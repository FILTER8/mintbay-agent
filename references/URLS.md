# Mintbay URLs (v0.1)

All URLs below are public pages or image endpoints. Use full absolute HTTPS URLs in agent replies.

## Individual Mintbay.fun NFT (current)

Token page: `https://mintbay.fun/collections/{chainId}/{contractAddress}/{tokenId}`

Token OG card: `https://mintbay.fun/collections/{chainId}/{contractAddress}/{tokenId}/opengraph-image`

Example: `https://mintbay.fun/collections/4663/0x2b1943a3279021B336eE172D59D5048a4bD090C4/1`

Post the token page as a plain text URL to X to make its OG card discoverable; X preview caching is not guaranteed.

## Individual NFT (legacy Mintbay.xyz)

Share page: `https://mintbay.xyz/token/{chainId}/{contractAddress}/{tokenId}`

Direct image: `https://mintbay.xyz/api/art/{chainId}/{contractAddress}/{tokenId}.png?size=800`

Working token share page:

`https://mintbay.xyz/token/4663/0x2eE6305804dD94F7ff695C5Ab1f3AE805f317653/68`

For X, share the page URL, not the raw image endpoint. Mintbay provides server-side OG/X metadata. X controls card display/caching.

## Gallery

Manual gallery explorer: `https://mintbay.xyz/gallery`

Gallery share page:

`https://mintbay.xyz/gallery/share?chain={chainId}&collection={address}&ids={id-list}&grid={columns}&gap=20&margin=68&scale=100&bg=white&labels=0`

`ids` is a comma-separated list of numeric IDs, URL encoded in the final URL. `grid` is the number of columns. For known-working social cards use no more than 16 selected NFTs.

Verified example:

`https://mintbay.xyz/gallery/share?chain=4663&collection=0x2eE6305804dD94F7ff695C5Ab1f3AE805f317653&ids=13%2C57%2C60%2C78%2C86%2C91%2C106%2C113%2C150&grid=3&gap=20&margin=68&scale=100&bg=white&labels=0`

The gallery share page includes X card metadata, and its PNG is generated by Mintbay. This URL is a static selection, not a verified ownership certificate.

## Formatting rules

1. Validate `chainId`, Ethereum-style `0x` contract address and positive integer token IDs.
2. Always return an actual URL with every placeholder replaced.
3. For X replies, put the URL in its own plain-text line (no Markdown anchor syntax).
4. Do not claim a link will definitely show an image in all contexts; preview generation depends on X.
5. Do not use arbitrary unverified RPC or image URLs to infer ownership.
