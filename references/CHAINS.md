# Chains

The current working end-to-end NFT and gallery sharing demonstration is on **Robinhood Chain mainnet, chain ID 4663**, for 8x8Portait:

`0x2eE6305804dD94F7ff695C5Ab1f3AE805f317653`

Mintbay also supports other EVM networks through its website, but **do not assume the server-side PNG/gallery endpoints support every NFT contract or metadata encoding**. Verify the token page and image endpoint before promising sharing compatibility.

The skill does not require a connected wallet for opening public pages. For selecting *a user's owned NFTs*, the agent needs an explicitly provided owner address and reliable ownership lookup.
